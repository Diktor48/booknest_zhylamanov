# BookNest

ЛР 3: каталог из 40 книг, поиск, фильтры, сортировка и список желаемого с сохранением в браузере.

## Запуск

Открыть папку проекта в VS Code и запустить `index.html` через Live Server. Либо из папки проекта:

```sh
python -m http.server 5500
```

Адрес: http://localhost:5500/index.html. Для ESM-модулей нужен локальный HTTP-сервер; открытие HTML через `file://` не подходит. Backend для этой лабы не нужен.

## Проверка JavaScript

```sh
npm ci
npm run lint
```

Используется базовая конфигурация ESLint. Если преподаватель выдаст свою, нужно применить её и повторить проверку.

## Структура ЛР 3

- `data/books.js` — 40 книг и пять жанров; рейтинги и доступность учебные.
- `lib/books.js` — чистые функции фильтрации, сортировки, списка желаемого и проверки сохранённых данных.
- `ui/render.js` — одна функция `render(state)` обновляет интерфейс; текст добавляется через `textContent`.
- `main.js` — один объект `state`, обработчики событий и `localStorage`.

Проверить: совместить поиск, жанр и доступность; сменить сортировку; добавить книгу в список, перезагрузить страницу и удалить её. «Сбросить» очищает фильтры, сохраняя список желаемого. Несуществующий запрос показывает подсказку. Ключ сохранения — `booknest:catalog:v1`; повреждённые данные или запрет хранилища не блокируют приложение.
