# Дерево компонентов и состояние — ЛР 5

Схема составлена перед переносом реализации на React. Стили из ЛР 2 сохраняются.

```text
App — фильтры, текущая страница, список желаемого, ошибки сохранения
├── Header — навигация и вычисляемый счётчик списка
├── CatalogPage
│   ├── FiltersPanel — контролируемые поля, состояние принадлежит App
│   ├── SearchResults — результат запроса и повторная загрузка
│   │   ├── Spinner
│   │   ├── EmptyState
│   │   ├── ErrorBox → Button
│   │   └── BookList → BookCard → Badge, BookCover, Button
│   └── Pagination → Button
├── BookDetails — результат запроса деталей выбранной книги
│   ├── Spinner / EmptyState / ErrorBox
│   └── BookCover, Badge, Button
├── Wishlist → EmptyState / BookList → BookCard
└── Footer
```

## Владельцы состояния

| Данные | Владелец | Причина |
| --- | --- | --- |
| Поисковая строка, жанр, сортировка, доступность | `App` | Одни значения нужны полям, запросу API и сохранению |
| Номер страницы | `App` | При изменении фильтров возвращается к 1 |
| Список желаемого | `App` | Общий для каталога, деталей книги и счётчика в шапке |
| Ошибка сохранения | `App` | Показывается независимо от выбранного экрана |
| Результат поиска, статус сети, ошибка, повтор | `SearchResults` | Относятся к жизненному циклу одного запроса; изменения фильтров отменяют старый запрос |
| Данные и статус выбранной книги | `BookDetails` | Отдельный запрос по ID; отменяется при смене книги или закрытии страницы |
| Экран и ID книги | URL, читается в `App` | Не дублируются в состоянии: `index.html` и `book.html?id=…` — две входные страницы Vite. Полноценный роутер вводится в следующей лабораторной |

Счётчики списка и страниц, признак выбора книги и доступность кнопок вычисляются при рендере. Копии этих значений в состоянии не хранятся. Для запросов используется размеченное объединение `loading | success | empty | error`, а не несколько несогласованных флагов.

Минимум пять презентационных компонентов не имеют собственного состояния: `Button`, `Badge`, `Spinner`, `EmptyState`, `ErrorBox`, `Header`, `Footer`, `FiltersPanel`, `BookCard`, `BookList`, `Wishlist`, `Pagination`, `BookCover`.

Повторное использование: `Button` — карточки, сброс, пагинация, повтор; `Badge` — карточки и детали; `Spinner` — поиск и детали; `EmptyState` — поиск, список и отсутствие ID; `ErrorBox` — поиск и детали.

Скриншот реального дерева: [`react-devtools.png`](react-devtools.png). Использован официальный `react-devtools-inline`: слева работающее приложение в iframe, справа дерево и состояние `App`. Временная среда съёмки не входит в приложение. Для демонстрации на защите можно открыть вкладку Components расширения React DevTools после `npm run dev`.
